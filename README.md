# Digital Clock Using HTML, CSS and JavaScript

A simple and responsive Digital Clock built using **HTML, CSS, and JavaScript**. The clock dynamically displays the current time and updates automatically in real time.

## 🚀 Features

* Displays the current time in real time
* Automatically updates every second
* Simple and clean user interface
* Responsive design
* Beginner-friendly JavaScript project

## 🛠️ Technologies Used

* **HTML** – Structure of the application
* **CSS** – Styling and layout
* **JavaScript** – Real-time clock functionality

## 📂 Project Structure

```text
Digital_Clock_using_js/
│── index.html
│── style.css
└── script.js
```

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/sayaliphanse14-prog/Digital_Clock_using_js.git
```

2. Open the project folder.

3. Open `index.html` in your browser.
